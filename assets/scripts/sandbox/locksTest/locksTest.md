# 🧪 Page de test — Écluses

Cette page HTML est une **page sandbox** utilisée uniquement pour effectuer des tests visuels autour des écluses.

Elle ne fait **pas partie de l’application principale**.

## 🎯 Objectif

La page permet d’afficher, de manière volontairement simple et directe, l’ensemble des écluses des canaux sur une carte Leaflet.

Elle s’appuie sur certaines fonctions existantes de l’application réelle afin de gagner du temps pendant les essais.

## ⚠️ Avertissement

Ce code est :

- non maintenu.
- non optimisé.
- non destiné à la production.
- susceptible d’être modifié ou supprimé à tout moment.

Il sert uniquement à faire des essais rapides et à visualiser les données de façon brute.

## 📍 Accès

Depuis la racine du projet, la page est accessible à l’adresse suivante :

```txt
/assets/scripts/sandbox/locksTest/locksTest.html
```

## 🧱 Rôle dans le projet

Cette page appartient au dossier sandbox, qui regroupe des scripts ou pages expérimentales.

Elle ne doit pas être considérée comme une fonctionnalité officielle de l’application.
